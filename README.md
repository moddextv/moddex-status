# moddex-status

Uptime and health monitoring for [moddex.tv](https://moddex.tv), a reverse index
of Twitch moderator and VIP roles.

Polls each service, records response times and uptime history, and publishes the
result at **status.moddex.tv**. It shares nothing with the services it watches:
a status page that goes down with them would not be worth much.

Documentation for the whole project lives in the `moddex-workspace` repository.
